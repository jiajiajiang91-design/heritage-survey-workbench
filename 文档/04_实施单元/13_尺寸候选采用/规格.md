# 尺寸候选采用 · 规格 v1.0

本单元将尺寸候选的一次性批量写入改为逐条核对、修正、采用和驳回，并纠正资料转写被标为实测的问题。

## 一、依据

本单元落实核心 PRD v4.0 的 F02、F05、F11 及第 3.1 节第 2 至 5 条，界面文档表 4、表 6、表 8 和技术架构第 1.4 节。目标用户和制作案例范围不变。

## 二、范围

用户在实测基准页处理尺寸候选，AI 调用与用量页提供前往核对页的入口。

| 操作 | 结果 |
|---|---|
| 查看 | 原文、数值、名称、资料和位置同时可见，选中资料在右侧预览 |
| 核对 | 每条选择采用、驳回或暂不处理；默认暂不处理，不按模型确定度自动选择 |
| 修正 | 修改名称和毫米数值，保留原文；存疑、修正、同名异值需要核对说明 |
| 采用 | 用户逐条声明已核对原资料，再保存实际所选集合 |
| 驳回 | 填写原因后保存；不进入可用尺寸 |
| 重新核对 | 保留旧处置，生成新的处置记录；界面采用最新处置 |
| 复用 | 提供有稳定事实引用的已采用尺寸读取函数，供后续构件表单引用 |

## 三、业务与数据规则

人工采用只表达本次使用决定，不改变原始资料性质。

- 每条处置绑定候选、运行、原始行、资料、原文及位置。模型原值不变时保留模型来源；修改后记录人工来源及原模型信息。采用命令记录责任人。
- 候选和原记录不覆盖；不同候选的相同行号不可互相替代，同一候选行重复提交相同处置不重复写入。
- 数值必须为有限正数，名称非空；资料引用必须存在且可用。未知数值保持空白，不填默认尺寸。驳回可以记录资料缺失，不形成可用尺寸。
- 同名异值只提示可能冲突，用户说明核对依据，双方来源均保留。不自动合并为同一物理尺寸。
- 提交失败保留全部草稿；保存期间阻止重复提交。命令已提交而刷新失败时明确告知已保存。
- 新事实使用既有 FactEnvelope 和 CommitFacts，不扩展数据库或模型输出契约。原有缺少候选关联的转写记录保留，不能猜测补配来源。

## 四、界面要求

候选区位于实测基准页主区，先显示待核对，再显示尺寸记录，右侧复用资料预览。

候选按一次运行分组，逐行显示原文和来源，采用值用名称、数值两个字段，处置为普通选择控件。错误就近显示；已处理行显示结果并可重新核对。保存前列明本次采用与驳回数量，实际内容在原行可见。无待处理候选时不展示空白大表单。

沿用现有令牌与控件，1280 px、1440 px 下可阅读和操作，键盘可访问来源、处置和数值字段。基准摘要分别表达现场记录、资料转写与形制假设，不以实测标签概括资料转写。

## 五、技术选择与不做

沿用事实记录并保存类型化处置信息，比新增候选处置数据库减少迁移范围，能直接向构件表单提供事实引用。

本单元不实现构件几何编辑、模型精度验收、跨资料语义自动合并或完整 T-DL-01。构件识别候选的逐条采用由后续构件单元处理。V02 仍需在尺寸进入实际成果后才可判定通过。
