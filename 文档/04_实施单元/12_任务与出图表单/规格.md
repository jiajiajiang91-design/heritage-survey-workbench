# 任务与出图表单 · 规格 v1.0

本单元用普通表单替换任务图幅与视图的 JSON 输入，并让图纸样式页可以编辑同一份成果要求。

## 一、依据

范围来自核心 PRD v4.0 的 F01、F12、F13，界面文档表 4、表 9，以及技术架构第 1.4 节。

本单元只完成 V01 所需的任务输入部分。候选、构件、几何制作与完整 T-DL-01 在后续单元验收，不在本单元提前判定通过。

## 二、范围

用户在任务卡和图纸样式页维护同一套图幅、视图与图签要求。

| 对象 | 可编辑内容 |
|---|---|
| 任务 | 名称、范围、适用约定、成果目录 |
| 图签 | 标题、修订标记 |
| 图幅 | 图号、图名、标准或自定义宽高；新增和移除 |
| 视图 | 图名、图种、比例、所属图幅、视口位置和大小；新增和移除 |
| 方向 | 常用正交方向，保留已有自定义方向；需要时按普通数值字段修改 |
| 剖切与详图 | 剖切位置、法向、裁切范围；从当前项目选择构件与资料 |
| 构件范围 | 使用当前项目的构件类型；未取得资料时可按任务填写类型名称 |

## 三、业务与数据规则

表单编辑只改变用户明确修改的字段，保留已有任务中的方向、引用、剖切与裁切信息。

- 内部键由程序创建并保持稳定，不要求用户输入；所有提交仍通过既有任务 schema 和命令入口。
- 数值不能为空、非有限或不满足对应正值约束；视口不能超出图幅，方向必须有效，剖切与详图缺少必要信息时不可提交。
- 移除图幅前处理其引用视图，不能产生孤立引用。构件与资料选项来自当前项目，旧引用缺失时显示问题而不静默删除。
- 图幅和视图草稿在保存失败后保留。保存期间阻止重复提交，只有写入成功才退出编辑。
- 更新显示本次变化和影响；当前影响计算不完整时明确提示，不以空结果宣称没有影响。
- 改任务保留旧定义与旧成果，新成果需要重新生成。本机正式签发权限不变。

## 四、界面要求

每个图幅和视图使用可折叠的编辑区域，主要字段先显示，方向数值与局部范围按需展开。

任务卡显示完整任务表单，图纸样式页复用成果要求编辑部分。标签用中文并明确单位，字段错误就近显示。主操作为保存，次操作为取消；在图幅和视图区域分别提供新增操作。已有生成图纸保留预览，不以草稿冒充新生成成果。

沿用现有视觉令牌和表单组件，在 1280 px 与 1440 px 下检查输入、校验、保存和取消。不得要求填写 JSON 或内部对象编号。

## 五、不做

本单元不扩展点云、几何内核、自动尺寸采用、跨项目构件库或正式签发，不新增助手可执行动作，不改已发布站点。
