# 输出单位转换 · 规格 v1.0

本单元使任务的输出单位实际作用于成果，同时保持物理尺寸和图纸比例。

## 一、依据

本单元落实核心 PRD 的 F01、F09、F12 及 V03，接续单元 17、21、22。

产品规则见核心 PRD 第 3.1 节，数据与格式依据见技术架构第 1.5 节。课堂依据为辅导 13 的任务属性与单位、对象数据规范要求。实施前设置仅保存与展示；本单元接通生产管线。

## 二、范围与规则

毫米、厘米、米均有实际文件转换与独立回读证据。

| 范围 | 判定规则 |
|---|---|
| 内部几何 | 采用值、坐标、BRep、容差及来源保持毫米；单位转换不改变稳定身份与依据 |
| IFC | 单位声明与顶点同步转换，回读恢复毫米后核对大小与位置 |
| GLB | 保持格式规定的米坐标，三种任务单位下物理大小相同 |
| DXF | 模型坐标、单位声明、原生长度尺寸及模型空间长度参数同步转换；可编辑实体保留 |
| 图面 | 明确长度单位，保留小数；标高仍为米；纸面毫米和比例不变，PDF、SVG、PNG 使用同一文字 |
| 当前成果 | 修改单位后保留旧文件和模型，提示需重新生成；旧单位成果不能计为符合当前要求 |
| 兼容与恢复 | 缺可选单位按旧毫米行为读取，旧记录哈希不因读取改变；新数据随项目包保存和恢复 |

使用同一内部墙体长度 6100.5 mm，三种输出对应 6100.5 mm、610.05 cm、6.1005 m。GLB 长度始终为 6.1005 m，1:50 图纸上的对应长度为 122.01 mm。实际精度按已有几何与网格容差检查，关键尺寸转换计算不取整。

## 三、实施边界

现有事实派生、已有规格及直接提供规格三条路径均读取当前任务单位。

规格和矩阵的 outputUnit 为可选字段，不设置解析默认值；新生成时显式保存。两侧 worker 校验有限单位集合。验证从实际文件回读，分别检查单位、坐标、原生尺寸显示值和纸面比例，并通过篡改验证检查有效性。浏览器检查任务修改、旧成果提示、重新生成及刷新。

## 四、不做

本单元只验收当前已有格式的单位转换。

STEP、RVT 与 Revit 实机交换另按原条件执行。真实建筑识别、完整制作和 V03 全项资格不因内部转换测试通过而完成。
