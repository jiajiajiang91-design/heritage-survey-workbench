# 任务创建与资料准备 · 规格 v1.0

本单元把分步项目创建改为单页任务设置，保存实际资料后进入资料工作区。

## 一、依据

本单元落实核心 PRD v5.0 的 F01、F02，范围限于任务字段、草稿保存与资料准备。

- 核心 PRD 第 3.3、3.4、4.5 节，独立创建制作任务原型。
- 技术架构第 0、1.4 节；保留单一命令写入和旧包读取。
- 首页单元 16 已通过，预览核对另开后续单元。

## 二、范围与规则

成果编制人员在一页填写任务、建筑和目标，图纸参数在生成前补齐。

| 项 | 实施内容 |
|---|---|
| 任务 | 名称、建筑、现状测绘目的、目标成果、毫米或厘米或米；单位默认毫米并可见 |
| 补充信息 | 项目或村落、建筑类型、主要结构选填；不推断未知属性 |
| 资料 | 按必需、建议、额外补充选择文件；目标变化更新要求说明，不判定文件名即可覆盖 |
| 保存 | 保存任务并准备资料；无资料可保存，不宣称已生成预览。有效字段和实际文件入库，失败单独显示 |
| 修改 | 任务卡编辑基本设置；旧任务不自动补目的、单位或目标；出图要求独立编辑 |
| 恢复 | 保存失败保留表单；已建任务不重复创建，逐文件失败不影响后续文件；重新进入及回导保持字段 |

首次预览条件为字段完整且至少一份可读建筑资料；本单元只准备资料，不调用预览或模型识别。保存草稿仍校验任务名称、建筑名称及至少一个目标，避免建立无法识别的空任务。

## 三、界面与数据

页面沿独立样板的信息顺序实现，初次保存后进入资料清单。

采用单页双栏：任务与折叠补充信息在左，三层资料在右，底部取消、保存草稿与保存任务并准备资料。有未保存内容时提供保存后返回或继续编辑；保存失败留在本页，保留填写内容和所选文件。文件标为待保存，保存期间显示正在保存。任务卡普通设置和图纸设置分别操作。

新增可选 productionSetup，包含 buildingId、purpose、outputUnit、targets、projectGroup；建筑增加可选类型与主要结构。CreateProject 可同时提交任务，ReplaceTaskDefinition 可同时修订同一建筑；旧字段缺失可读取，建筑关联必须属于当前项目。资料 preparationLevel 可选；未登记的旧资料不推断层级。

几何内部仍以毫米计算。此单元保存输出单位选择，不将当前模型或图纸宣称为已按新单位生成；导出单位转换随成果单元验收。

## 四、不做

TIFF 派生、候选预览和连续案例在后续单元实施。

本单元不重新生成演示包，不调用真实模型，不更改既有成果、来源或检查资格。
