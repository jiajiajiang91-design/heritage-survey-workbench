# 构件参数与尺寸引用 · 规格 v1.0

本单元用普通构件表单替换建模 JSON 输入，使已采用尺寸直接进入模型生成参数。

## 一、依据

本单元落实核心 PRD v4.0 的 F04、F05、F07、F08 及第 3.1 节第 3、5、7 条，界面文档表 4、表 6、表 9 和技术架构第 1.4 节。单元 12、13 已完成任务设置和尺寸采用，完整制作案例条件不变。

## 二、范围

用户在构件清单填写当前生成器支持的构件参数，在三维模型页发起生成。

| 对象 | 本单元操作 |
|---|---|
| 基本信息 | 名称、构件类型、资料位置、材料、所属构件及引用资料 |
| 长方体 | X、Y、Z 向长度和中心位置 |
| 圆柱体 | 半径、长度、轴向和中心位置 |
| 轮廓挤出 | 逐点轮廓、挤出长度、轴向和原点 |
| 尺寸引用 | 六种长度字段可选择已采用尺寸，显示本次读值与来源；解除引用后才可直接填写 |
| 修订 | 编辑本项目构件输入记录，保存后重新生成，保留旧输入和旧成果 |

仅呈现生成器已有的实体形式。需要其他形制时列为不支持，不把复杂构造替换为通用形状后声称完成。坐标、长度和材料缺失时不预填为实测值。

## 三、业务规则

引用尺寸记录表达尺寸来源与更新关系，人工采用不把资料转写变成实测。

- 长度大于零，坐标有限，名称、类型、位置出处和至少一份可用资料必填。轮廓至少三点，重复点、零面积和自交不可提交。
- 每个引用保存原采用记录的引用标识。生成时按同一对象与尺寸字段读取最新处置；驳回、失效、引用缺失或非毫米数值时停止，不能继续使用旧数值。
- 生成对象同时引用构件记录和实际使用的尺寸记录。构件位置来源、概念引用和未修改参数保留，不在生成过程中丢失。
- 修改尺寸记录后，无须再次填写相同长度。重新生成使用新值，旧几何版本和成果不变。
- 修改构件输入时保留既有关系、未确认说明和未编辑参数。新项目不推断承托、接触或搭接，未声明关系不等于已经检查关系。
- 已有演示模型如果没有原始构件输入记录，不允许从展示模型自动反写测绘事实；界面说明需在空项目依资料制作。
- 保存前显示变化与需要重新生成的提示，失败保留草稿；提交后读取失败说明已经保存。本机签发规则不变。

## 四、界面方案

构件清单主区先显示待制作输入和新增入口，选择一条后展开编辑，右侧继续展示当前资料。

表单由基本信息、形状参数和资料依据三部分组成，位置明确标注毫米、轴向和中心或原点。尺寸字段在直接填写和选择已采用尺寸之间切换；选择后显示数值和资料名称，用户无须填写内部编号。

每次只编辑一个构件，保存、取消相邻，已有记录可再次编辑。内部键由程序生成，类型选择使用中文名称。未确认内容和旧参数按需展开。三维模型页提供返回构件清单的入口，不保留 JSON 输入。

按 1280 px 和 1440 px 检查真实字段、错误、键盘及表单与资料区关系。

## 五、技术选择

沿用既有构件事实、几何契约和生成命令，增加可选长度引用字段及生成前解析，比在页面复制尺寸值更能保持后续修订一致。

引用解析在基础设施层执行，工作台只提供选择与校验。旧无引用记录按原方式生成；生成器和 CAD 文件格式不变。构件写入服务接收类型化参数并返回明确状态，所有写入仍经项目命令。

## 六、不做

本单元不扩展几何内核、点云、构件识别模型动作、复杂曲面、跨项目构件库或正式签发。构件连接的可视编辑和完整 T-DL-01 制作另行验收，已有连接数据保持原样。内部自动测试仅证明输入到生成规格的传递，完整 V03、V04 仍需实际模型与图纸文件。
