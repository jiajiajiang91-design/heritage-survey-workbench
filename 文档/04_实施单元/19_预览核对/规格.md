# 预览核对 · 规格 v1.0

本单元把可读资料提取结果集中为只读预览，再经既有操作采用或修正尺寸。

## 一、依据

本单元落实核心 PRD v5.0 的 F02、F05 和第 3.4、4.5 节，接续单元 18。

技术架构第 1.4 节定义 PreviewReadModel，只读查询不写事实。演示项目定义第 3.5 节规定 T-DL-03 的长度与相对标高不得混用；本单元完成产品和内部交互验收，真实模型的 T-DL-03 连续运行另记证据。

## 二、范围与规则

生成预览首先提取资料已有标注，不要求完整建筑几何。

| 项 | 规则 |
|---|---|
| 开始 | 有完整本次制作设置及至少一份勾选的可读资料，调用当前尺寸提取；成功进入预览核对，失败可重试并保留旧结果 |
| 预览查询 | 汇总当前项目尺寸候选、既有构件候选、原件、采用记录和缺项；查看、筛选、定位不写事实或生成资格 |
| 原文与结果 | 并列原标注、换算毫米值、候选或已采用状态、来源文件及图上位置；修正后使用最新采用记录 |
| 定位 | 有合法归一化区域则叠加原图标记；无区域或越界说明具体缺项，保留文字位置并支持临时原图定位，不虚构坐标 |
| 长度与标高 | 候选可声明长度或相对标高，人工采用时类型可见可修改；长度须正值，相对标高允许零与负值，不作为构件长度引用 |
| 核对 | 转到尺寸核对并聚焦原资料，复用当前逐条采用、修正与驳回；未知信息保持待核对，原候选和旧记录保留 |
| 输出 | 导出预览核对清单与来源说明，包含原标注、候选、最新采用值、类型、状态、来源哈希和位置；候选未核对时不宣称为已确认成果 |
| 恢复 | 刷新及 ZIP 回导后预览由已存记录恢复；重读失败保留此前结果，缺原件或位置不伪造可定位状态 |

当前候选没有完整类型化几何输入，因此本单元只提供原图位置和清单预览；不会从单条尺寸或像素位置推断三维构造。后续有合格参数时按既有生成流程验收。

## 三、界面与数据

资料页主操作为生成预览，整理资料阶段增加预览核对页签。

预览页左侧候选清单、状态筛选、缺项和导出，右侧原图与候选位置，支持选条目定位、转入尺寸核对和返回资料。图像尺寸与标记继承单元 18 的恒等映射，候选位置不成为实测位置。

TranscribedDimension 增加可选 quantityKind 与 region；旧候选可读，不自动补定位。已采用记录增加可选标注类型，旧记录按其原正长度规则读取；新表单显示可修改的长度默认值，相对标高需要人工明确选择。PreviewReadModel 只在工作台查询层计算，不存储第二份项目数据。

## 四、不做

本单元不将内部交互测试替代真实模型识别或完整制作验收。

不导入 T-DL-03 的独立预期为系统候选，不修改 T-DL-01 失败记录，不生成缺少参数的三维或图纸；真实模型任务须遵守项目既有外部资料传输确认规则。
