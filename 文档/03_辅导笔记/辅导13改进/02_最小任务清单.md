### 1.1 首个样板的任务

首个样板是“创建制作任务并准备资料”，制作目的为现状测绘，目标成果由用户选择。

预览对象是资料支持的建筑模型或图纸。首批样板先确定页面和资料准备方法；首批尺寸核对任务已固定为 T-DL-03，完整制作 T-DL-01 保留原任务与资料恢复条件。

## 2. 最小资料清单

资料清单按成果要求组织，必需资料支持主体表达，建议资料支持进一步核对，额外补充支持局部细节。

依据：录音 28:13 至 31:43。表 2 采用导师的三层方式，并按已有模型与测绘图纸目标给出准备要求。它是待验证的任务输入方案，使用时需绑定具体建筑和目标成果。

**表 2：本页显示的资料要求**

| **层级** | **资料** | **对应结果** | **检查内容** |
|---|---|---|---|
| 必需 | 平面图或可读平面草图 | 平面与主体位置预览 | 建筑对象、范围、方向、比例或尺寸依据可辨 |
| 必需 | 尺寸记录或带尺寸图纸 | 目标成果的尺度及定位 | 单位、总体宽度和进深；主体模型或立面还需高度依据 |
| 必需，选择立面时 | 对应方向的立面图或照片 | 指定立面预览 | 建筑和方向一致；图纸尺寸或比例、照片对应的已知尺度可定位 |
| 必需，选择剖面时 | 指定剖面图或构造测绘记录 | 指定剖面预览 | 剖切位置、楼层与构造关系、需要表达的高度和厚度有依据 |
| 建议 | 其他方向的照片、立面及历史图纸 | 核对不同视图及对象关系 | 与同一建筑、时期和任务范围对应，冲突可定位 |
| 额外补充 | 局部详图、构件尺寸、节点照片、说明 | 增加有依据的局部细节 | 明确所指对象和记录位置 |

同一份图纸可以同时满足平面和尺寸要求，不要求重复上传。首次处理以至少一份可读建筑资料为起点。三层清单显示目标资料的覆盖要求，缺项不妨碍查看已有部分；内容提取和核对随后在可视预览中进行。

图上未标注的隐藏部位、构造尺寸或目标视图缺项，在预览中显示具体待补充内容。用户可以补充资料或调整本次成果选择。结果核对依据为原始图纸、记录和照片的对应关系。

### 2.1 现有样本的使用

现有样本应按资料条件选择可执行任务，并保留已经记录的实验结果。

[T-DL-01 预检](../../05_验证证据/23_T-DL-01资料预检/预检记录.md)当时未接入 TIFF，且楼层、开口、构造及定位依据不足。单元 18 已接通 TIFF 读取；完整主体任务仍需补齐上述依据。只验证已标注尺寸的核对预览使用独立任务 T-DL-03，保留原预检结果。

高都和构造样板可支持已生成成果的交互展示。选作从原始资料开始的制作案例时，还需固定原件与任务要求，直接从空项目运行。

## 3. 课堂要求的完成检查

每项修改都要回到课堂问题和实际结果核对，状态在独立审查记录中更新。

**表 3：后续检查范围**

| **要求** | **核对内容** |
|---|---|
| 业务价值 | 一至两项核心指标能说明投入和收益，实际测试与估算有依据 |
| 首页 | 根据使用者展示任务进展，能找到进行中与待处理建筑；多项目支持检索 |
| 任务定义 | 建筑、目的、成果、单位明确，模板与附加属性有业务用途 |
| 资料输入 | 三层资料、缺项引导、逐步补充、文件状态和成果预期可理解 |
| 数据定义 | 建筑、构件、属性和来源可定位，编号稳定，用不同样本核对 |
| 预览与核对 | 用户能同时查看建筑对象和原始依据，修正后看到更新 |
| 页面信息 | 保留当前任务必要内容，技术字段按需要展开 |
| 文档精简 | PRD 可直接理解业务与页面；交互、异常、数据、验收齐全且无重复要求 |
| Agent 精简 | 职责与原则清楚，删减前后同任务产出质量保持 |
| 连续操作 | 输入到导出实际可运行，错误可恢复，结果与资料及任务要求相符 |
