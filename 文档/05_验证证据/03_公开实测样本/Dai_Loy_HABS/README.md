## 三、样本与来源

该样本是 HABS CA-2071 W 的美国历史建筑记录，不用于证明中国古建专业适用性。

文字说明记载调查于 1979 年夏完成，图纸和文字于 1980 年编辑。本项目只引用其历史记录，不把其中“现状”“业主”等用语解释为今日状态。

- [Library of Congress 原记录](https://www.loc.gov/pictures/item/ca0469/)
- [HABS 建筑说明](https://tile.loc.gov/storage-services/master/pnp/habshaer/ca/ca0400/ca0492/data/ca0492data.pdf)
- [NPS 教学资料](https://www.nps.gov/articles/000/locke-and-walnut-grove-havens-for-early-asian-immigrants-in-california-teaching-with-historic-places.htm)

下载记录保留的权利说明区分政府制作图像与其他来源复制图像。使用时保留来源机构、调查号、作者和原始链接，不将原调查成果声明为本项目自有成果。
