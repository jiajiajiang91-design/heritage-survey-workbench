## 一、一处更正

本表初版把 v3 判为画得很细的界面稿，不是定义完整的设计系统，并列出 53 处缺口。**这个判断是错的，已作废。**

错在查询方式。初版只在 `04 产品原型 v3` 页面上查变量，而该查询只返回这一页**用到的**变量。设计系统实际定义在 `01 基础规范` 与 `02 组件` 两个页面上，共 138 个变量、4 个集合，结构完整。

这与本项目此前三次漏检同源：**用一种查询方式得到空结果，就当成不存在，而不是当成自己没查到。** 正确顺序是先问文件里有没有设计系统，再看具体页面用了其中哪些。

## 二、设计系统的结构

两层令牌：Primitives 是色阶原料，Semantic Color 全部以别名指向 Primitives，Geometry 与 Typography 各管尺寸与字体。

| 集合 | 变量数 | 模式 | 管什么 |
|---|---:|---|---|
| Primitives | 35 | Value | 中性灰十三阶，蓝绿琥珀红紫五色各三到五阶，一个遮罩色 |
| Semantic Color | 56 | Light | 底色、文字、边框、图标、操作、来源标记、状态，全部别名 |
| Geometry | 26 | Value | 间距十二档、圆角六档、描边两档、控件与图标各三档 |
| Typography | 21 | Value | 两个字体族、三个字重、七档字号、七档行高、两档字距 |

Semantic Color 只有 Light 一个模式，没有暗色模式。

## 三、节点级用法

上面的变量是定义，下面是十九屏里的实际用法。用法从节点属性取得，说明某个变量或某个数值具体用在哪。

字阶部分尤其要看这里：Typography 集合定义了七档字号与七档行高，但**哪个字号配哪个行高配哪个字重**是组合规则，变量表里没有，只能从节点上取。
