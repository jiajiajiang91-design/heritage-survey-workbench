# 三档断点实测

日期：2026-08-22。依据：实施单元 06 外壳与令牌，第三组。

## 一、验证方式

窄屏三档在产品原型 v4 上**一屏都没画**，取值按裁决记录第一节第 5 条推导。因此没有原型可对照，只能实测实现的行为。

浏览器面板在本次会话未显示，截不了图。改为读计算样式：在开发服务器 `127.0.0.1:5173` 上逐档改视口，读 `.app-shell` 的 `grid-template-columns` 与相关元素的 `display`。这比截图更硬：截图看的是渲染结果，计算样式看的是实际生效的规则。

## 二、实测结果

| 视口宽 | 三栏实测 | 左栏主体 | 横向滚动 | 判定 |
|---:|---|---|---|---|
| 1440 | 240 / 820 / 380 | 显示 | 无 | 与 v4 画板逐像素一致 |
| 1280 | 240 / 660 / 380 | 显示 | 无 | 边界值，三栏仍全开，符合不小于 1280 全开 |
| 1200 | 240 / 916 / 44 | 显示 | 无 | 助手栏已收起，左栏未动 |
| 1000 | 56 / 900 / 44 | 隐藏 | 无 | 左栏收为图标条，标题与主体隐藏 |

1440 一档的 240 / 820 / 380 与 v4 十九屏的画板量测完全相同，三栏之和等于 1440。

## 三、途中修掉的两处

**最小宽度写成了断点值。** 原来 `body { min-width: 1180px }`，我先改成 `var(--layout-breakpoint-md)` 即 1024，结果 1000 宽时页面横向滚动 — 等于把第三档挡在门外。改为按三栏各自的下限算：图标条 56 加中栏最小 640 加助手条 44，得 740。

**拿顶栏高度当图标条宽度。** 第三档的左栏宽写成了 `var(--layout-topbar-height)`，取值恰好都是 56，但语义不同，改一个会连带改另一个。补 `layout/rail-icon` 专用令牌，描述里写明与顶栏同值属巧合。

## 四、令牌与媒体查询的绑定

CSS 不允许在媒体查询里用 `var()`，两处边界只能写字面值 1279 与 1023。`visual-spec.test.ts` 有一条把它与令牌绑住：断点必须等于 `--layout-breakpoint-lg` 减一与 `--layout-breakpoint-md` 减一，改令牌不改媒体查询会失败。
