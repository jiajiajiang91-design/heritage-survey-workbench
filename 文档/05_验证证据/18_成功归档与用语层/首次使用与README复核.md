# 首次使用与 README 复核 v1.1

线上版本能够让第一次使用的测绘与文保成果生产人员理解产品用途，并沿高都项目查看从资料到归档的八个阶段。关键页面已经区分展示数据与真实工程责任。

日期：2026-08-25。线上地址：<https://heritage.jiajiajiang.com/>。验证版本：`a2fe50c`，分支 `codex/professional-workbench-rebuild`。

## 一、核验依据

本轮以核心 PRD 的目标用户、产品目标、当前范围和非目标为判断基准，不以页面是否能打开代替产品验收。

| 判断项 | 依据 | 首次用户应得到的认识 |
|---|---|---|
| 目标用户 | 核心 PRD 2.1 | 产品服务于古建测绘、文保勘察和成果生产人员 |
| 产品目标 | 核心 PRD 2.5 | 一栋建筑形成一份连续档案，同一份数据驱动模型、图纸、检查和归档 |
| 责任关系 | 核心 PRD 3.4、4.5 | AI 提供理解与候选，程序生成确定性成果，专业人员确认和签发 |
| 当前范围 | 核心 PRD 3.1 | 单栋建筑、本机单用户、完整成果生产链路 |
| 非目标 | 核心 PRD 3.2 | 不代替现场测量、专业判断、法定签发或多人项目平台 |

## 二、验证方法

验证同时覆盖全新浏览器自动巡检、用户可见浏览器操作和独立首页复查。

1. 使用全新 Chrome 用户目录访问线上站点，等待两个展示项目首次装载。
2. 从高都项目的建立任务开始，依次进入整理资料、核对实测、核对构件、记录现状、生成图纸、检查签发和交付归档。
3. 实际打开照片、三维模型、DXF 和 PDF，并翻到 PDF 第二页。
4. 先被动浏览，确认不会自动调用模型；再主动获取建议、提问通面阔，并查看 token 与费用变化。
5. 抽查清式大木构造样板的结构化资料、完成状态和问题数量。
6. 独立产品设计验收角色使用另一份全新浏览器状态复查项目首页，不读取实现代码。

独立复查只覆盖项目首页。浏览器连接在进入项目后中断，因此项目内部结论来自全新 Chrome 自动巡检和用户可见 Chrome 的逐项操作。

## 三、首次使用结论

第一次使用者现在可以从项目列表直接理解产品服务对象、主要输入、处理过程和结果，不必先阅读 PRD 才能开始。

| 用户问题 | 页面给出的答案 | 结果 |
|---|---|---|
| 这是给谁用的 | 项目列表说明面向古建测绘与文保成果生产人员 | 通过 |
| 产品处理什么 | 资料、实测、模型、图纸和归档成果处于同一条可追溯流程 | 通过 |
| 从哪里开始 | 高都项目卡提供进入任务，进入后默认停在建立任务 | 通过 |
| 下一步做什么 | 左侧八阶段与页面顶部下一步按钮共同提示 | 通过 |
| 是否为真实工程数据 | 项目列表、任务卡、检查签发和归档页均说明展示数据边界 | 通过 |
| 谁承担专业责任 | 本机不能签发；随包记录明确为流程演示记录，不构成真实工程签发 | 通过 |
| 能得到什么结果 | 可查看三维模型、SVG、DXF、PDF、检查记录和成果包 | 通过 |

首次装载支持先显示项目清单，再分包载入完整内容。系统会重试单个失败的项目包，并保留已经载入的项目。用户可以通过“继续载入”补齐缺少的项目，不需要清空本机数据。

2026-08-25 使用 `tools/workbench-sweep.mjs` 访问线上站点。两个项目的名称、规模和数据边界在 5.2 秒后出现。高都项目在 55.4 秒后可进入，两个完整项目在 127.4 秒后载入完毕。项目包合计约 42 MB。

首次使用者需要等待约 55 秒才能进入第一个完整项目，仍不满足快速体验要求。后续应拆分模型与图纸资源，并使用对象存储或 CDN 按需加载。

## 五、AI 与用量核验

AI 调用由用户主动发起，被动浏览不会产生模型调用。

- 被动浏览八阶段时，建议调用数保持为 0。
- 点击获取本步建议后，建议次数增加 1。
- 提问项目通面阔后，助手根据项目尺寸记录回答 9600 mm，并说明依据。
- AI 调用与用量页显示模型 `kimi-k2.6`、真实调用次数、token 用量与估算费用。
- 页面说明服务器当日汇总和项目内运行明细的统计范围，费用按公开单价估算。

当前用量页是服务器当日汇总，不是访问者会话账单。该限制已在页面说明，后续若进入多人生产环境，应改为按组织、项目和调用主体分账。

## 七、当前边界

当前版本可以用于完整产品展示和单机流程验证，但不能作为真实工程生产系统对外承诺。

- 展示实测值用于产品体验，不替代现场实测。
- 流程演示签发记录只说明展示链路完成，不构成真实工程签发或交付资格。
- 浏览器本机项目库不支持多人实时协作、组织权限或服务端统一档案管理。
- 生产环境需要补充身份、权限、服务端项目库、数字签名和正式责任流程。
