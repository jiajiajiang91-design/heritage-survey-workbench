# 公网展示部署说明（heritage.jiajiajiang.com）

目标环境：腾讯云上海轻量应用服务器（4 核 4G，OpenCloudOS，IP 49.235.158.54），域名 `jiajiajiang.com` 已备案。架构：nginx 提供 HTTPS 与静态前端，`/api` 反代到本机 Node 服务，Node 按需拉起 Python CAD 进程。Kimi 密钥只存在服务器的 `/etc/gujian/server.env`。

## 一次性开通步骤

1. DNS：`jiajiajiang.com` 解析加一条 A 记录，主机记录 `heritage`，值 `49.235.158.54`。
2. 证书：腾讯云控制台 → SSL 证书 → 申请免费证书（`heritage.jiajiajiang.com`）→ 签发后下载 Nginx 格式，两个文件放服务器 `/etc/nginx/certs/`。
3. 防火墙：轻量服务器控制台 → 防火墙，放行 TCP 80 与 443。
4. 服务器上以 root 执行 `deploy/setup-server.sh`（代码用 rsync 推上去时先 `export GUJIAN_SKIP_CLONE=1`）。
5. 编辑 `/etc/gujian/server.env` 填 `KIMI_API_KEY`，`systemctl restart gujian-server`。

## 日常更新

本地改完、测试过、演示包重建过之后：

```bash
rsync -az --delete --exclude .git --exclude node_modules --exclude .venv --exclude "apps/server/.data" ./ root@49.235.158.54:/opt/gujian/app/
ssh root@49.235.158.54 "chown -R gujian:gujian /opt/gujian/app && sudo -u gujian env HOME=/home/gujian PATH=/usr/local/bin:/usr/bin:/bin bash -c 'cd /opt/gujian/app && pnpm install --frozen-lockfile && pnpm run build' && systemctl restart gujian-server"
```

服务器部署目录没有 `.git` 时，可从已经推送到 GitHub 的分支更新：

```bash
curl -fsSL https://raw.githubusercontent.com/jiajiajiang91-design/heritage-survey-workbench/main/deploy/update-from-github.sh -o /tmp/update-gujian.sh
bash /tmp/update-gujian.sh main
```

脚本会保留 `apps/server/.data`，重新构建前后端，更新 Nginx 配置并重启服务。执行前必须确认目标目录是 `/opt/gujian/app`。

## 公网防护（服务端已内建，环境变量开启）

`GUJIAN_PUBLIC_HOST` 设了值即公网模式：Host 放行该域名、会话 Cookie 加 Secure、写操作按每日限额计数（助手对话与生成作业分开限，单 IP 与全站两层，超限返回 429 与中文说明，东八区零点清零）。额度默认值与调整项见 `server.env.example`。

## 已知限制

- 单机单进程：CAD 作业并发为 1，第二个访客的生成请求会排队。
- 限额计数在进程内存里，重启服务当日计数清零（展示场景可接受）。
- 演示包更新要重新 rsync 并让访客端在项目列表点"更新演示项目"。
